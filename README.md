# Automated Data Cleaner

A beginner-friendly MATLAB project that automatically cleans a messy Excel dataset by detecting missing and invalid values, removing problematic rows, calculating summary statistics, and exporting the cleaned data to a new Excel file.

## Features

- Reads data from an Excel spreadsheet using `readtable`
- Detects missing values
- Checks temperature, humidity, and rainfall for invalid values
- Removes rows containing missing or invalid data
- Calculates average temperature, humidity, and rainfall
- Displays a summary of the cleaning process
- Exports the cleaned dataset to a new Excel file

## Data Validation Rules

The program considers a row invalid if:

- Temperature is missing, below -50°F, or above 130°F
- Humidity is missing, below 0%, or above 100%
- Rainfall is missing or below 0

Any row containing one or more of these problems is removed.

## Example Results

The sample dataset contains 10 weather observations. After cleaning:

- Original rows: 10
- Rows removed: 6
- Rows remaining: 4
- Average temperature: 73.25°F
- Average humidity: 56.75%
- Average rainfall: 0.43

## Project Files

- `automated_data_cleaner.m` - MATLAB script that performs the data cleaning
- `messy_weather_data.xlsx` - Original dataset containing intentional errors
- `cleaned_weather_data.xlsx` - Cleaned dataset generated by the MATLAB script

## MATLAB Concepts Used

- Tables
- `readtable` and `writetable`
- Missing-data detection
- Logical operators
- Logical indexing
- Conditional statements
- Basic statistics
- File input and output

## How It Works

1. Load the Excel dataset into MATLAB.
2. Identify missing and invalid values.
3. Mark rows that fail the validation rules.
4. Remove invalid rows using logical indexing.
5. Calculate statistics from the remaining data.
6. Display a cleaning summary.
7. Export the cleaned data to a new Excel file.
